# S-A-SS-Portfolio

This is the source code for the official S&A Smart Solution agency portfolio website.

It's a static multi-page site built to showcase our websites, logo designs, and video production work, outline our workflow for each category, and let clients get in touch.

## Live Site

You can view the live website in `Deployments`.

## About the Site

The site is built using standard HTML, CSS, and vanilla JavaScript, featuring light/dark theme persistence, RO/EN language switching, scroll reveal animations, responsive mobile navigation with category dropdowns, and an idle-prioritized background video loader with a lightbox overlay player. It is hosted directly through GitHub Pages, meaning the files in this repository match what is served on the live site.

## Project Structure

- `style.css` - Shared stylesheet used across all pages
- `html/` - HTML pages (`homepage.html`, `websites.html`, `logos.html`, `videos.html`)
- `js/` - Modular JavaScript files (`hamburger.js`, `theme.js`, `lang.js`, `reveal.js`, `video-overlay.js`, `video-queue.js`)
- `media/` - Portfolio videos (`cabinet-stomatologic.mp4`, `service-auto-1.mp4`, `service-auto-2.mp4`, `service-gsm.mp4`) and media assets
