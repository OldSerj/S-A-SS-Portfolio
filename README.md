# S-A-SS-Portfolio

This is the source code for the official S&A Smart Solutions company portfolio website. 

It's a simple, static site built to showcase our recent projects, outline our services, and let people know how to get in touch. 

## Live Site

You can view the live website in `Deployments`.

## About the Site

The site is built using standard HTML, CSS, and a bit of JavaScript. It is curr hosted directly through GitHub Pages, meaning the files in this repository are exactly what you see on the live site.

## Project Structure

*   `index.html` - The main homepage
*   `css/` - Stylesheets
*   `js/` - JavaScript files
*   `images/` - Project photos, logos, and other assets
